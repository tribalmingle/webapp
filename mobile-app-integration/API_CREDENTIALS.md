## 📱 Mobile App Configuration

### Required Environment Variables

```bash
# API Base URL
API_BASE_URL=https://tribalmingle.vercel.app/api

# Optional: For development/staging

```

**That's it!** The mobile app doesn't need any other credentials because:
- Authentication is handled via JWT tokens (obtained after login)
- All backend processing happens on the server
- API keys are never exposed to clients

## 🔄 Environment Variable Workflow

### For Backend Changes
1. Update variables in Vercel Dashboard
2. Redeploy if needed
3. No mobile app changes required

### For Mobile App
1. Store only `API_BASE_URL` in app config
2. Obtain JWT token via `/api/auth/login`
3. Store JWT securely (iOS Keychain, Android Keystore)
4. Include JWT in all API requests

## 🔐 Security Best Practices

### For Mobile App Developers
1. **Never hardcode API keys** in mobile app
2. **Use secure storage** for JWT tokens (Keychain/Keystore)
3. **Implement certificate pinning** for API calls
4. **Validate server certificates**
5. **Use HTTPS only** (no HTTP fallback)
6. **Implement token refresh** when JWT expires
7. **Clear credentials** on logout
8. **Use biometric authentication** where available

### Token Management
```typescript
// Good ✅
const token = await SecureStore.getItemAsync('auth_token');
apiClient.defaults.headers.Authorization = `Bearer ${token}`;

// Bad ❌
const API_KEY = 'hardcoded_key_12345'; // Never do this!
```
