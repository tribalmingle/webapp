## Design System

**Colors:** Purple gradient (#5B21B6→#312E81), Pink/coral accent (#FF6B9D→#F97316), White text
**Cards:** 20-24px radius, glass-morphism, frosted effect
**Buttons:** Pill-shaped (48-52px height), gradient fills
**Typography:** Bold headings (24-32px), body (14-16px), SF Pro/Roboto
**Spacing:** 16-20px padding, 24-32px margins
**Navigation:** Logo + 3 icons (top), 3-5 pill buttons (bottom)

Use the uploaded gaming gear app as the design foundation. Match its vibrant colorfulness, professional polish, modern card designs, clean typography, perfect spacing, and attention to detail. Adapt this beautiful aesthetic for a dating app context.

Key elements to match from the reference:
- Vibrant purple gradient backgrounds
- Pink/coral gradient buttons and accents

- Glass-morphism effects
- Perfect spacing and alignment
- Professional UI polish
- Engaging, colorful aesthetic

The result should be a premium dating app with the same level of beauty and professionalism as the reference image.

SCREEN PURPOSE:
This is the main "Discover" screen where users swipe on profile cards to like or pass on potential matches. It should feel engaging, premium, and culturally authentic.

TOP NAVIGATION BAR:

MAIN CONTENT AREA:

## Prompt Variations

### For Different Screen Types:

**List View Screens:** Adjust prompt to show vertical scrolling list instead of cards
**Form Screens:** Replace card content with input fields and form elements  
**Modal Overlays:** Add transparent dark overlay behind centered modal card
**Empty States:** Replace content with centered icon, message, and CTA button

### For Different Color Modes:

**Dark Mode (Default):** Use prompts as written above
**Light Mode:** Replace purple gradients with white/light gray, invert text colors
