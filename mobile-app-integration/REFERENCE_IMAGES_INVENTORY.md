## 🎨 Design System Extracted from References

### Color Palette (from discover.png)
```
Background Gradient: #7C3AED → #EC4899 (purple to pink)
Primary Purple: #7C3AED
Primary Pink: #EC4899
Accent Orange/Coral: #FF6B35 to #FF8C42 (active states, borders, tribe names)
Dark Navy: #1E1B4B to #2D1B69 (top bar, buttons)
White: #FFFFFF (text, primary icons)
Glass Effect: rgba(255, 255, 255, 0.15) with backdrop-blur
```

### Navigation Structure
**Top Bar:**
- Dark purple pill-shaped bar (~30-40px height)
- "TRIBAL MINGLE" logo with icon (left)
- Search and Messages icons (right)
- Circular profile photo (far right)

**Bottom Navigation:**
- Order: Home | Matches | Like | Chat | Settings
- Active state: Orange gradient fill
- Even spacing across bottom
- Dark semi-transparent background

### Card Design
- Large glass-morphism cards
- Border radius: ~20-24px
- Backdrop blur effect
- White semi-transparent background

### Buttons
- Circular action buttons (X = dark, Heart = orange gradient)
- Profile borders: Orange/coral rings around circular photos

### Typography
- Bold white text for names
- Orange/yellow text for tribe names
- Clean, modern sans-serif font
